An interactive Excel dashboard built to analyze hotel booking patterns, cancellation trends, guest behavior, and hotel performance metrics.

🎯 Project Overview

This dashboard helps analyze hotel booking data and uncover key business insights related to cancellations, customer segments, room preferences, and booking trends.

The dashboard provides:

✅ Total Bookings KPI

✅ Total Cancellations KPI

✅ Hotel Type Performance

✅ Guest Type Analysis

✅ Room Type Analysis

✅ Monthly Booking & Cancellation Trends

✅ Interactive Year Filter using Excel Slicers

⚙️ Tools & Techniques Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Dashboard Design
- KPI Reporting
- Data Visualization

📈 Key Insights

📌 Total Bookings: **119,391**

📌 Total Cancellations: **44,224**

📌 Cancellation Rate: **37.04%**

📌 Couples contributed the highest booking volume.

📌 City Hotels experienced more cancellations than Resort Hotels.

📌 Desired room types accounted for the majority of bookings.

📌 Booking activity peaked during the summer months.

🧠 Business Problem

Hotel booking cancellations can significantly impact occupancy rates and revenue.

This dashboard helps identify patterns in cancellations across different customer segments and hotel categories, enabling better operational and pricing decisions.
